🔧 How to Start the Server:

Option 1: Double-click launcher

  1. Go to the frontend folder
  2. Double-click START_UI.bat
  3. Wait for "Serving HTTP on 0.0.0.0 port 8080"
  4. Refresh this page

Option 2: Manual start

  1. Open PowerShell in the frontend folder
  2. Run: python -m http.server 8080
  3. Keep that window open
  4. Refresh this page

Option 3: Open file directly

  1. Navigate to frontend folder
  2. Right-click standalone.html
  3. Select "Open with" → Your browser
  4. Note: Some features may not work without a server
